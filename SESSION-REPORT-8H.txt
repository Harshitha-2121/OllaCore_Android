PART 5 - CRASH FIXES (verified, not claimed)
--------------------------------------------------------------------------------
21. WEBRTC ClassNotFoundException org.webrtc.Environment (call screen):
    - Root cause PROVEN by disassembly: com.infobip:google-webrtc:1.0.45036
      is desynced - PeerConnectionFactory$Builder references Environment in
      5 places (only referrer in all 398 classes), classes.jar omits it,
      while libjingle .so exports nativeCreate/nativeFree. So builder()
      itself threw on any call-screen open.
    - Fix: app-provided org/webrtc/Environment.java wrapper with exactly the
      expected API + ProGuard keeps. No dependency added/swapped.
    - Verified ON DEVICE: voice call reached Connected twice, zero linkage
      errors; end-call clean.
22. Country rememberSaveable crash (login): Country object -> saveable Int
    index (+ coerceIn guard). Same latent enum crash fixed for HomeTab and
    ChatFilter (persist name strings). Project-wide grep: no other custom
    saveables remain.
23. Found while testing: onboarding skipped on fresh installs (stale closure
    + routing race) - fixed with rememberUpdatedState + onboarding guard.
24. Found via unit tests (fixed at root cause, nothing suppressed):
    - ForwardSecrecyManager: re-added members stayed revoked forever (real
      security bug) - re-admission now clears revocation.
    - MimeValidator: intermediate executable segments (script.sh.txt) now
      flagged per documented policy + MZ header detection.
    - MlsMessageHandlerTest: millisecond-colliding ids -> monotonic counter.
    - MimeValidatorTest: byte-literal + assert API fixes.
25. Instant-close report from user: could not reproduce here; requested
    logcat protocol. Note: no google-services.json exists - FCM touches are
    runCatching-guarded; if a trace shows Firebase init failure, that is the
