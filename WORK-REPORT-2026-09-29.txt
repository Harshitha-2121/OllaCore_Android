1. CHAT BLOCK - PRESERVE PRE-BLOCK HISTORY (10:44 AM, a1acaab)
================================================================
- Bug: blocking a contact wiped/hid the ENTIRE shared history, not
  just messages sent after the block.
- Root cause: block visibility had no time dimension - it was
  "sender blocked => hide every message from sender".
- Fixes:
  a. ChatPrefsStore: per-user block-event timestamps stored in
     blocked_at_json; re-blocking the same user overwrites the
     cutoff (new block hides from the new cutoff onward).
  b. New BlockFilter.kt (pure JVM logic, testable without Android):
     - messageCreatedAtMs(): parses server instants (ISO-8601 or
       epoch seconds/millis strings) to epoch ms.
     - blockedMessageHidden(): a message is hidden ONLY when its
       sender is currently blocked AND the message was created at
       after that sender's block event. Pre-block history, other
       senders, and unblocked periods stay visible.
     - Unknown/unparseable timestamps FAIL CLOSED (hidden while
       blocked) - safe default, no accidental leak.
  c. ChatViewModel: blockedAtCache + isBlockedMessage() applied to
     the live-message path, history-load path, and the in-memory
     filter; legacy blocks (no stored timestamp) backfilled; block
     toggle no longer clears local history.
- Files: ChatPrefsStore.kt (+33), BlockFilter.kt (new, +43),
  ChatViewModel.kt (+40 / -8).
