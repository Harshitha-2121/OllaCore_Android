  Core Properties Verified:
    ✅ Removed member cannot decrypt future messages
    ✅ Removed member CAN decrypt old messages (before removal)
    ✅ Re-added member gets new epoch access
    ✅ Multiple rotations maintain forward secrecy
    ✅ Each epoch has unique key (key isolation)
    ✅ Old keys marked as revoked with reason and timestamp
  Manager Capabilities:
    - onMemberAdded(principalId): Adds member, marks pending rotation
    - onMemberRemoved(principalId, reason): Removes member, triggers rotation,

    - canDecrypt(memberId, epoch): Checks if member can decrypt at given epoch
    - getRevokedBeforeEpoch(epoch): Returns members revoked before given epoch
    - getKeyForEpoch(epoch): Returns key ID for epoch
    - getActiveMembers(): Returns current active members
    - getRevokedMembers(): Returns revoked members
    - needsRotation(): Checks if session needs rotation
    - getRotationCount(): Returns total rotations
    - reset(): Clears all state
